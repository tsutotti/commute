# 通勤快適 完成版

つと専用・個人利用の超小型乗換PWA。

## 仕様
- 烏丸御池 ⇄ 京都 ⇄ 大阪
- 片道・全区間
- JRは新快速のみ
- 地下鉄は烏丸線
- 乗換1分以上
- 現在時刻より1分後から検索
- 最速到着順で3候補
- 平日 / 土日祝を自動判定
- 祝日判定ロジック内蔵
- 手動時刻変更
- オフライン検索
- PWA / ホーム画面追加
- 起動時の更新チェック機構
- 更新失敗時は手元のデータで継続

## 時刻表
